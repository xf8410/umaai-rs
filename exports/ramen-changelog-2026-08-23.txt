## 2026-08-23

### 拉面杯规则与阶段流转修复

- 修复固定比赛回合的阶段短路：比赛回合现在仍正常经过 `RamenSelect -> SpecialSelect -> Train`；只有进入 `Train` 后动作列表才收敛为固定比赛，避免比赛回合无法吃面、无法选择隐藏风味，并确保赛后未决事件仍由正常 `AfterTrain` 流程处理。
- 统一吃面效果落地时机：选择拉面及隐藏风味方案后，在进入训练阶段前统一完成诀窍消耗、剧本 PT 增加、当前拉面状态、地区分身、羁绊效果和面板刷新；训练动作不再重复承载拉面决策。
- 补全三阶段和合并决策路径：标准路径使用“选面 -> 选隐藏风味 -> 训练”，合并决策路径可一次提交拉面和目标后直接进入训练；两条路径复用相同效果落地逻辑。
- 修复第三年 `hint_special` 估值：全员 Hint 生效时按实际全部触发计价，并纳入卡片 `hint_count_bonus`；普通多 Hint 场景仍按随机命中概率估值。
- 超级拉面由固定选项改为动态选择：依据各属性剩余上限缺口和对应类型支援卡数量评估三个候选，不再无条件固定选择第二项。

### 手写策略修复与恢复

- 恢复此前简化过程中遗漏的长期决策：普通支援卡早期羁绊、剧本友人首次点击/解锁进度、Hint、属性预留、动态体力成本、连续失败期望和即时收益牺牲上限重新参与训练动作评分。
- 修复友人外出动态估值接线：低体力守门原本提前返回休息，导致五段友人外出动态价值永远无法参与比较；现在会在合法恢复动作中比较休息与友人外出，并遵守分年累计使用配额 `[1, 3, 5]`。
- 友人五段事件按当前局面动态估值：考虑实际可获得体力、干劲溢出、属性、技能 PT、最大体力、万能材料来源和事件链进度；第三段不再依赖固定体力阈值。
- 修复事件选项漏项：事件评分补入 Hint 等级、羁绊和永久最大体力，避免系统性低估友人及支援卡事件。
- 恢复吃面/训练事务约束：吃面前先判断本回合是否会训练；一旦吃面，训练阶段只允许从五种训练中选择，避免吃面后休息或外出浪费当回合加成。
- 恢复动态隐藏风味方案：不再永远选择隐藏风味消耗最少的方案，而是结合吃后库存平衡、后续可制作拉面数量和当年剩余回合进行选择。
- 保留当前训练窗口耦合：拉面选择会考虑被覆盖训练的即时训练值、有效人头和彩圈数量；关闭会干扰真实窗口的随机分身前瞻。
- 加入 Cook2 式诀窍边际库存成本：使用凹函数估计 A/B/C 诀窍和隐藏风味的机会成本，并按年度剩余进度及 RMJ 状态折扣。
- 修复推荐配置漂移：正式基线使用 v29 `special-only` 配置，启用动态隐藏风味方案并关闭已验证退化的 deadline 非训练回合吃面例外。

### 配卡画像策略（实验）

- 新增普通支援卡构成识别，固定友人卡不计入五种普通卡数量；友人 `303054` 仍为所有拉面杯测试卡组的第六张必带卡。
- 为精确的 `3速 + 1耐 + 1智 + 1友人` 构成增加第二、三年专用吃面窗口：
  - 耐力或智力训练存在至少两个有效人头时形成吃面窗口；有效人头仅统计普通支援卡和剧本友人，不统计 NPC、记者或理事长。
  - 同一窗口继续按人头数和彩圈数提高优先级。
  - 速度训练默认不作为普通吃面目标；仅在诀窍总库存临近溢出，或速度达到双彩以上的大窗口时开放速度例外。
  - 只从实际覆盖目标训练位置的当前可制作拉面中选择，并按训练、友情、PT 和 Hint 效果比较候选。
- 三速专用规则不应用于其他构成；`2速2耐1智`、`2力3智`、`2速1耐2智`、`1速1耐3智` 保持 v29 通用策略，用作隔离和泛化对照。

### 固定种子基准与结果

- v29 每组 300 局固定种子矩阵中，`special-only` 获得当前最佳平均结果：平均评分 `58906.3`、平均技能 PT `7824.0`、评分 P10 `55253`、最低分 `51979`、最高分 `65375`。
- 相比 v28，v29 `special-only` 平均评分提高 `320.2`，平均技能 PT 提高 `67.4`。
- deadline20/deadline35/deadline50 三组结果完全一致且平均评分降至 `56960.7`，确认原 deadline 逻辑实际退化为“只要未达标就开放非训练回合吃面”的布尔硬例外；该功能已从正式基线关闭，后续如恢复必须基于目标真实可达性判断。
- 新增五种指定配卡的成对矩阵：每种构成 300 个相同规则种子，逐局比较 v29 `special-only` 基线与配卡画像策略；总计 3000 次完整育成。矩阵会输出实际六张卡 ID、平均评分、技能 PT 和 RMJ 三年全通率。

### RNG、基准与可复现性

- 规则层随机拆分为回合固定流、事件流和策略交互流：角标/人头分布/Hint、事件链及训练/分身随机互不污染；跨策略成对实验共享规则主种子。
- 基准局号通过稳定派生函数生成决策种子和规则主种子，不再依赖线程调度；相同 `(base_seed, run_idx)` 可跨分片和并行度复现。
- 搜索 rollout 使用当前推荐拉面策略，避免生产入口、MCTS rollout 和 benchmark 各自复制参数后漂移。
- 增加配卡矩阵及结果 CSV；Python 仅用于读取 CSV 和生成汇总，不参与正式 Rust 策略执行。

### 工程与 CI

- 拉面策略及规则改动均已固化为 Rust 源码；正常构建、测试和运行不需要执行 Python 补丁。
- 新增纯源码上游检查，从干净 checkout 执行 `cargo fmt --all -- --check`、无默认 feature 编译、核心库测试和默认 feature workspace 编译。
- 对已提交 Rust 源码执行全 workspace rustfmt，消除历史局部格式化造成的 CI 差异。
- 一次性实验 patch 脚本及历史矩阵 workflow 仅属于实验分支基础设施，不应包含在最终上游 PR；上游提交应只保留必要 Rust、测试、配置和说明文档。

### 已知限制

- 三速专用窗口仍属于经验规则，必须以五配卡成对矩阵结果决定是否进入正式推荐策略。
- 当前地区选择仍以地区静态效果和卡组类型数量为主，尚未联合优化年度配方需求、诀窍来源、可制作碗数和属性缺口。
- 超级拉面动态选择目前使用属性缺口和卡型数量的近似值，尚未完整预演 URA 训练分布。
- deadline 可达性模型当前关闭；未来应仅在“不吃即不可达、吃后可恢复可达”时开放非训练回合例外。
