# NN rollout 基策 vs 手写 大样本（50 局）—— 显著正向

- 权重：release `nn-ramen-v1`（model.onnx，754→245，308917 参数）
- 配置：search_n=8，stages=train，seed=61444，CRN 同 seed 配对
- 工具：`nn_rollout_probe`（CPU tract-onnx），run 39191683635

## 判读结论

| 指标 | 值 |
|---|---|
| 样本 n | 50 |
| 手写均值（SD） | 52809.6（3976.9） |
| NN 均值（SD） | 57387.3（3024.3） |
| 配对差均值 | **+4577.8** |
| 配对差 SD / SE | 4114.5 / 581.9 |
| 配对 t | **7.867** |
| 胜率（win/loss/tie） | 88%（44/6/0） |

**结论：NN rollout 基策显著优于手写 rollout 基策（t=7.87，df=49，p≪0.001）。**
- 不仅均值高 4578 分，方差还更小（3024 vs 3977），即 NN 更稳定
- 按算法噪声纪律（CRN 配对显著提升才进主线），**达到「有提升，继续」标准**
