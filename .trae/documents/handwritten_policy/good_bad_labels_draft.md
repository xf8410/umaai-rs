# 拉面杯手写逻辑的玩家语义与缺口

> 本文记录玩家如何判断一手操作是好是坏，以及当前手写策略还缺哪些判断。
> **只评价操作质量，不把坏发牌或坏局面直接归咎于策略。**
>
> 机制事实以 `glossary.md`、`ramen_memo_cn.md` 和 `ramen_story_flow.md` 为准；截至 v44 的正式策略与实验结论以 `ramen_policy_handoff_v44.md` 为准。

## 1. 使用原则

玩家语义分为三层，不应混用：

1. **机制事实**：例如做面消耗 5 个诀窍，面效只持续当前回合。
2. **局面描述**：例如本回合没人、没彩、友人没来，这是发牌，不一定是操作问题。
3. **操作质量**：例如有真正大盘却省面、小盘硬吃、吃歪、吃后被迫休息，才是需要策略解释的好坏手。

标签有三种用途：

- **打分项**：进入 `score_breakdown`；必须先确认现有期望值没有计过，避免双重计分。
- **健康指标**：跑批统计和低分局诊断；不直接改变决策。
- **硬守门**：仅用于不执行就会育成失败或确定非法/浪费的情况。

新增玩家语义应先进入健康指标，经同 seed A/B 验证后再决定是否成为打分项。不能因为语义听起来合理就直接增加权重。

## 2. 已确认并应保留的正式方向

| 玩家手法 | 当前结论 | 策略含义 |
|---|---|---|
| 友人早点点出来并解锁 | 保留 | 首点、羁绊推进和解锁有长期价值 |
| 第一年不急着消耗友人出门 | `0/2/5` 已在 v44 胜出 | 第一年底累计 0 次、第二年底累计 2 次、第三年完成 5 次；正式代码暂仍是 `1/3/5`，需另行同步和回归 |
| 吃面后必须训练 | 保留保险门 | 防止吃完面去休息、出门或治病；它只能防空吃，不能自动防歪吃或小盘浪费 |
| 吃面对着当前真实训练盘面 | 保留 | 依据面覆盖位置与当前训练窗口耦合，不依赖随机分身前瞻 |
| 使用基础失败率作保守风险预算 | 保留 | 规则层仍应用真实减失败率；策略不能因面把失败率压低就无条件高估低体力硬踩 |
| 诀窍按边际库存和后续可做面估值 | 保留 | 三种诀窍偏科与隐藏风味灵活性分别估值 |
| 低体力跨 RMJ、5000、普通 PT 档 | 不晋级 | 当前一碗能过线不等于这回合值得硬踩，尤其普通 PT 档特判明显亏分 |
| 持续 deadline urgency | 保持关闭 | 旧逻辑方向错误，且会绕过正常恢复判断 |

### RMJ 用语必须准确

- 第三年 `<3500`：RMJ 失败。
- 第三年 `3500～4999`：RMJ 普通成功，但没有大成功。
- 第三年 `>=5000`：大成功，获得超级拉面额外效果。

因此“第三年低于 5000”不能统一标记为 RMJ 失败。健康指标必须拆成“RMJ 是否成功”和“是否达到 5000 大成功”两项。

## 3. P0：直接影响下一轮策略的缺口

P0 应先补齐可观测字段和诊断标签，再逐项做消融；除已确认规则外，不直接新增权重。

### 3.1 大盘吃面、小盘省面

**玩家判断**：面应吃在真正的大训练上，而不是只看当前训练显示值或当前能否做面。

盘面至少应记录：

- 各训练彩圈数及彩圈对应的支援卡；
- 支援卡人头、NPC 人头，二者不能等价计价；
- 有效 Hint 数与预计命中价值；
- 主属性、副属性、PT 的有效训练值；
- 属性是否接近真实上限，溢出后其他收益是否仍有效；
- 当前面是否覆盖最终选择的训练；
- 吃前/吃后失败率和体力转移；
- 吃后配方续航。

**待补标签**：`large_board_eat`、`large_board_skip`、`small_board_eat`。

**缺口**：当前 `ramen_window` 已看原始收益、人头和彩圈，但仍缺支援卡/NPC 分离、Hint 有效性、主属性方向、真实溢出和两回合体力的统一解释。

### 3.2 吃面对盘：正吃、歪吃、空吃

- **正吃**：面的关键效果覆盖最终训练，并有效放大当前盘面。
- **歪吃**：吃了面但最终训练不在关键覆盖范围，或主要词条没有兑现。
- **空吃**：吃面后休息、出门、治病，或者没有执行训练。
- **赛程浪费**：强制比赛前吃面，但面效没有在训练中兑现。

**待补标签**：`ramen_aligned`、`ramen_misaligned`、`ramen_empty`、`ramen_wasted_by_race`。

**现状**：`eat_requires_training` 已防大部分空吃；尚不能完整识别歪吃、弱正吃和强制赛程浪费。

### 3.3 吃后体力转移

**玩家判断**：第三年面能降低失败率，不代表低体力训练必赚。必须比较至少两个回合：

- 本回合硬踩收益；
- 训练后剩余体力；
- 下一普通回合是否被迫休息；
- 是否错过下一回合更大的训练；
- 下一次确定恢复距离；
- 有马赛后恢复与超级拉面每回合恢复是否即将接管。

**待补标签**：`eat_then_forced_rest`、`eat_vital_transfer_good`、`eat_vital_transfer_bad`。

**现状**：已有第三年训练前后体力和终盘恢复 horizon 的实验设施，但正式 preset 的短缺权重为 0；v44 已证明不能用单纯跨线特判绕过恢复门。缺的是两回合收益比较，不是另一条过线奖励。

### 3.4 配方续航

**玩家判断**：库存总数足够，不代表仍能按配方做面。应判断：

- 吃后还能做几种当前已选地区面；
- 每种可做面还能做几碗；
- 三种诀窍是否偏科；
- 隐藏风味是否被迫补普通缺口；
- 诀窍先进先出淘汰是否丢掉关键类型；
- 当前消费是否打空后续关键配方。

**待补标签**：`recipe_continuity`、`recipe_dead_end`、`special_forced_patch`、`queue_key_loss`。

**现状**：动态 SpecialSelect 已看吃后可制作种类与库存平衡，但还没有“每种可做数量”、关键配方缺口和队列淘汰的完整语义。

### 3.5 年末保线

**玩家判断**：临近 RMJ 时应保留至少一碗实际可做的面，不能只看总诀窍或抽象 PT 可达性。

应同时记录：

- 当前 RMJ 普通成功线缺口；
- 第三年 5000 大成功线缺口；
- 剩余可训练/可吃面回合；
- 当前和预计未来至少一碗可做面；
- 达到普通成功与冲大成功的优先级差异。

**待补标签**：`year_end_bowl_secured`、`year_end_recipe_stranded`、`rmj_fail`、`great_success_missed`。

**现状**：旧 `deadline_urgency` 只按 PT 缺口和碗数制造压力，方向错误且保持关闭。新逻辑必须从“保留可做配方”出发，不能复活旧紧迫度。

### 3.6 合宿前存体

**玩家判断**：合宿是固定的高价值训练窗口，进入合宿时体力不足并在第一回合被迫休息通常是坏手。

应记录：

- 合宿开始前体力；
- 合宿四回合训练次数、休息次数；
- 合宿第一回合是否被迫休息；
- 合宿前一到两回合是否有可替代的恢复动作；
- 合宿内强制比赛对可训练次数的影响。

**待补标签**：`camp_entry_vital`、`camp_first_turn_forced_rest`、`camp_training_count`。

**缺口**：当前动态体力按一般回合估值，没有显式表达合宿窗口的未来价值。

### 3.7 地区面按卡组选

**玩家判断**：地区面的友情倍率和覆盖训练应匹配卡组方向，不能所有 build 固定同一套第三年地区。

应结合：

- 速、耐、力、根、智卡数量与强度；
- 预期彩圈训练方向；
- `youqing × at_trains` 的有效覆盖；
- 单属性高倍率与多属性覆盖的差异；
- `pt_bonus`、配方和诀窍槽基础分配；
- 属性上限与当前养成方向。

**待补标签**：`region_build_aligned`、`region_build_misaligned`、`region_recipe_fit`。

**现状**：`issues.md` 已记录第三年地区固定组合及 `score_region` 缺 build 区分度的问题；该问题尚未解决。

### 3.8 早解锁与早出门分离

必须分别观察：

1. 第一次点到友人的回合；
2. 友人登场、点击事件和解锁回合；
3. 五次出门各自发生的回合；
4. 每次出门是否替代原本的休息；
5. 是否覆盖了本可进行的大训练；
6. 最终是否完成五段事件链。

**待补标签**：`friend_first_click_turn`、`friend_unlock_turn`、`friend_outing_turns`、`friend_outing_replaced_rest`、`friend_outing_overrode_training`。

**已确认节奏**：正式候选是累计 `0/2/5`。它表示第一年不消耗出门次数，不表示第一年不点友人或不追求解锁。

## 4. P1：用于解释低分局的缺口

| 缺口 | 玩家问题 | 建议先记录的诊断 |
|---|---|---|
| 前期点卡与开彩 | 是否用可接受的弱训练换到了关键羁绊和彩圈启动？ | 低羁绊卡人数、首彩回合、为羁绊牺牲的即时训练值 |
| Hint 有效性 | 是有效 Hint、废 Hint、重复 Hint，还是剩余技能池已空？ | Hint 技能、重复状态、可学习性、预计 PT 价值 |
| 诀窍偏科与队列损失 | 是材料总量不足，还是关键类型被挤掉？ | A/B/C 库存、队列淘汰类型、各配方缺口 |
| 属性真实溢出 | 主属性撞墙后，副属性和 PT 是否仍使训练有效？ | 分属性有效增量、PT 增量、上限损失 |
| 比赛与未来连战 | 当前多跑是否导致后续连战、体力或训练窗口损失？ | 强制/自选比赛、连续比赛长度、赛后体力 |
| 合宿利用率 | 合宿差是发牌差还是存体/操作差？ | 合宿盘面质量、可训练次数、被迫恢复次数 |
| 发牌差与操作差分离 | 低分是否在策略可控范围内？ | 每回合最佳可见盘面、实际选择、随机事件与人物分布摘要 |

## 5. P2：后续精调项

- 设施等级投资：弱训练换设施等级是否能在后续回收。
- 不同卡组的年初三碗模板：效果覆盖与配方槽生成联合选择。
- 五段友人事件逐段边际价值：体力、干劲、属性、PT、Hint 与隐藏风味的状态依赖价值。
- 均分与 P10 风险偏好：激进踩训练和保底恢复不应共用一套目标。
- 年末最后两三回合联合规划：当前吃面、下一碗可做性、RMJ 普通成功与大成功联合判断。
- 超极阶段三次训练：每回合 +20 体力、属性上限和 PT 上限的利用率。

## 6. 现有健康指标的修订

| 旧标签 | 修订后语义 |
|---|---|
| 训练失败就是坏手 | 改为记录行动前失败率、期望收益和是否存在安全替代；失败结果本身可能只是随机性 |
| 体力长期低于 35 | 保留为诊断，但需结合下一次确定恢复、终盘和合宿位置 |
| 年末 `eat_count < 5` | 仅作节奏诊断；不能为了凑次数在小盘或低体力时硬吃 |
| 第三年隐藏风味剩余就是坏手 | 改为判断是否错过了可兑现的大盘或 5000；剩余本身不是错误 |
| 出门晚于固定回合就是坏手 | 改为分别记录解锁和五次出门；采用按年累计 `0/2/5` 语义 |
| 第三年 `<5000` 是 RMJ 失败 | 拆为 `<3500` RMJ 失败与 `3500～4999` 未达大成功 |
| 属性接近上限仍训练就是坏手 | 改为按实际溢出损失、副属性和 PT 是否仍有效判断 |
| 有失败率就不应训练 | 删除绝对判断；按失败期望、尾部风险和替代动作判断 |

## 7. 仍然有效的硬守门

1. **free_race 达标**：不达标会直接导致育成失败，优先于一般评分。
2. **生病处理**：需要结合动作菜单和合宿规则选择治病或可替代恢复动作。
3. **吃面后必须训练**：当前正式保险门，防止当回合面效被空耗。
4. **友人跨年出门配额**：候选节奏为 `0/2/5`；正式代码同步前不能声称已经生效。

除上述已确认项外，P0/P1 标签默认先作为诊断，不得直接升级为硬守门。

## 8. 验证顺序

1. 先将正式 preset 的友人累计出门配额从 `1/3/5` 同步为 `0/2/5`，并用正式 `RecommendedRamenTrainer` 做同 seed 回归。
2. 为 P0 增加轻量诊断字段，先确认能区分大盘/小盘、正吃/歪吃/空吃和两回合体力转移。
3. 优先验证“大盘吃面”和“吃后体力转移”，不要重新测试已淘汰的低体力跨线特判。
4. 再补配方续航、年末保线与合宿前存体。
5. 地区面按卡组选择单独做跨 build 回归。
6. 每次只晋级一个语义项，使用共同种子比较均分、P10、PT、属性评分和配对胜平负。
7. 检查 `distribute_person` 中得意率影响“不出现”判定的已知机制风险；修复前只解释同规则 A/B，不把绝对收益直接等同实服。

## 9. 一句话准则

**友人早点点出来，但第一年别急着出门；面要吃在真正的大训练上。判断低体力吃面时，要看本回合与下一回合、配方续航和未来关键窗口，不能只看当前一碗是否跨过 RMJ、5000 或普通 PT 档。**
